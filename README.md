\# TrustVault



\## Project Overview

TrustVault is a document access management web application built with Python, Flask, and SQLite.



\## Features

\- User login and role-based access

\- Document creation and viewing

\- Grant viewer read access

\- Revoke viewer access

\- Audit logging for document access actions



\## Technologies Used

\- Python

\- Flask

\- SQLite

\- HTML



\## Run Locally

1\. Open Command Prompt in the project folder.

2\. Activate the virtual environment or use its Python executable.

3\. Run `venv\\Scripts\\python.exe app.py`.

4\. Open `http://127.0.0.1:5000` in your browser.



\## Current Limitations

\- Document creation stores text content rather than uploading files.

\- Access revocation has been implemented, but viewer access removal still needs verification.

\- This is a local demonstration application and has not been deployed publicly.



\## Testing

Login, document creation, access granting, and audit logging were tested locally. Further permission and security testing is still needed.
